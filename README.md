# Concrete Calculator — Android APK project

هذا المشروع يحول حاسبة الخرسانة المستقلة إلى تطبيق Android يعمل محلياً داخل WebView، بدون خادم Grok.

## بناء APK
1. افتح المجلد في Android Studio.
2. انتظر مزامنة Gradle.
3. من القائمة: Build → Build APK(s).
4. ملف APK يظهر عادة في `app/build/outputs/apk/apk/debug/app-debug.apk`.

## ملاحظات
- minSdk 23 (Android 6.0+).
- الحسابات والبيانات تعمل محلياً.
- لا يحتاج التطبيق إلى اتصال بالإنترنت بعد التثبيت.
- اسم التطبيق: حاسبة الخرسانة.
